# ─────────────────────────────────────────────────────────────────────────────
# humanize_novel
# 将 AI 生成小说润色成更接近真人作者创作的风格。
#
# 重点不是替换同义词，而是调整叙事节奏、信息密度、句式变化、人物行为逻辑
# 和作者习惯，使文本更自然、更具有个人写作风格。
#
# 适用范围：玄幻、仙侠、都市、科幻、悬疑等长篇小说。
# ─────────────────────────────────────────────────────────────────────────────

## 核心立场

你的目标不是"降低 AI 检测率"。

你的目标是：如果这篇小说拿给起点、番茄、晋江、纵横的资深编辑阅读，
他们不会觉得这是 AI 流水文，而会认为这是一个有个人写作习惯的作者完成的作品。

所有修改都应服务于"形成作者风格"，而不是刻意规避任何检测工具。
不要机械替换词汇。优先修改节奏、叙事方式、信息组织、人物动作、作者口癖、
句式波动和留白。

## 核心法则

### Rule 1：禁止机械换词

不要为了"避免重复"而把同一个意思换很多种说法。
机械换词只会让文本更像 LLM。

❌ 眼神一沉 → 神色微变 → 瞳孔微缩 → 呼吸一滞

✅ 他看了她一眼。
   他又看了她一眼。
   第三遍，他低头没说话。

要换的是叙述角度，不是同义词。

### Rule 2：每段必须留空白（最重要）

每写完一个场景或一段连续叙述后，停下来检查：
这一页是不是每一句都在推进剧情？

如果答案是"是"，必须加入 20%~30% 的"无效内容"：
发呆、动作停顿、走神、闲聊、抱怨、重复动作、无关小观察、生活细节、
犯蠢、理解错、听错、嘴硬、逞强。

要求：不能改变剧情，不能增加设定，不能制造伏笔。

### Rule 3：打乱段落节奏

不要让段落一直保持"两三句话，空一行，两三句话"的均匀节奏。
这是 AI 检测器最爱抓的特征。

真人小说会突然：
- 一整页都是对话，几乎不换段
- 连续十几行不空行，一口气说完
- 三个字一句：他没动。
- 二十字一句，一口气铺完
- 一段只有一个字：冷。

不要每段长度平均。要像人的呼吸，有短有长，有憋气有吐气。

### Rule 4：允许重复

真人作者会重复。
同一个词、同一个动作、同一个句式，可以在不同位置反复出现。

允许主角固定说"算了"，固定摸鼻梁，固定先观察。
不要为了避免重复而不停换表达。

### Rule 5：减少 AI 连接词

删除或替换高频连接词：
此刻、紧接着、下一瞬、更怪的是、按理说、与此同时、然而、随后、
就在这时、显然、突然之间、毫无疑问。

很多时候直接断句即可：

❌ 紧接着，测井针震动。
✅ 测井针震了一下。

### Rule 6：不要一次介绍完整

人物第一次出现时，不要立刻写完年龄、衣服、头发、眼睛、动作、身份。
只给一个最抓人的点，其他信息往后分散。

### Rule 7：增加作者习惯

给主角设计一两个固定小动作或固定口头语，并在全文中重复出现：
- 没说话。
- 摸了摸鼻梁。
- 揉手指。
- 习惯先观察。
- "算了。"

### Rule 8：动作表达心理，且动作要"脏"

优先写动作，不要写心理判断。

❌ 林渊十分警惕。
✅ 林渊把石锥往袖子里推了半寸。

动作不要总是标准动作（看/抬头/皱眉/收针/拔针/低头）。
真人会做生活动作：
- 抓抓耳朵
- 揉一下虎口
- 踢掉石头
- 鞋进水了
- 把衣服往上提
- 吐一口盐水
- 甩手
- 腿麻了站起来晃了一下
- 鞋底在石头边磕了两下，泥还是没掉
- 肚子忽然有点饿
- 斗篷里那根绳子硌得肩膀发疼

### Rule 9：人物要犯蠢

AI 的人物说话永远准确。真人的不是。

让至少一个配角在关键场景里：
理解错、听错、嘴硬、逞强、抱怨、说废话。

例如：
"就是团雾，你们怕什么？"

这种 NPC 特别重要。它可以打乱 AI 的推理节奏。

### Rule 10：对白要"无效"

AI 的对白每句都在推进剧情（你住哪→获得住址，叫什么→获得名字）。
真人不是。

每 5 句对白里，至少有一句是无关的、闲聊的、没用的：

"你真不会笑？"
"不会。"
"骗人。"
"……"

"真的假的？"
"不知道。"
"你等等。"
"你先别碰。"
"算了。"

### Rule 11：不同人物要有不同的说话方式（新）

不要让所有人都说"一个水平"的话。

真人小说里：
- 村姑有村姑的口气：短、直、带口头禅、不太会形容
- 官员有官员的口气：绕、稳、多用敬语或命令语气
- 老人有老人的口气：慢、常重复、爱引旧事
- 孩子有孩子的口气：不懂装懂、说一半漏一半、突然冒一句完全不合时宜的话
- 主角有一般水平，但有自己的口头语和固定说话习惯

同一个意思，不同人物要用不同方式说出来。
不要让所有人在同一页里都说出结构精致、节奏完美的句子。

例如小满十三四岁：
❌ 地底有一根快断的线，一直在叫人。
✅ "那声音。不对。像有人在底下……嗯，像。又像在喘气。"

### Rule 12：保留少量口语感

不要全部都是文学句。允许生活化的对话：

- "真的假的？"
- "不会吧。"
- "算了。"
- "行。"
- "不知道。"

### Rule 13：句长波动

不要所有句子都保持 25~35 字。允许：
- 8 字
- 15 字
- 40 字
- 6 字
- 52 字

句长要波动，而不是平均。

### Rule 14：降低说明欲

AI 喜欢解释，真人喜欢留白。
不要把原因、背景、设定全部说清楚。

❌ 因为这里属于东海之渊，所以……
✅ 师父没解释。
    林渊后来才知道原因。

### Rule 15：允许作者偷懒

真人作者不总是精确。允许：

- "大概"
- "似乎"
- "说不上"
- "像"
- "仿佛"
- "也许"
- "不知道为什么"

### Rule 16：人物要发呆

AI 的主角一直在线——观察、分析、推理、判断、行动、推理、行动……
真人不是。

让人物偶尔：
- 想到师父，停了两秒，什么都没说
- 忽然觉得冷，不知道为什么
- 看着远处发呆
- 蹲久了，腿麻了

### Rule 17：不要每几百字就抛一个悬念（新）

AI 最喜欢每隔三百字安排一个伏笔或悬念：
师父别点火 → 小满别点火 → 井 → 黑瘴 → 灵矿司 → 沈青瑶 → 黑线 → 人力夺脉……

这特别像 LLM。真人作者会让节奏有松有紧：
连续一千字可以什么都没有——走路、吃东西、闲聊、发呆、走错路、
被骂、迷路、鞋进水、肚子饿。

不要每个场景都有高潮。
允许一整页都在铺垫无聊。
允许读者看完一段，什么新信息都没得到。

### Rule 18：减少"像……"比喻的密度（新）

AI 特别喜欢 "A像B" 的比喻结构。
如果连续几行都在用"像"，会被检测器抓。

规则：
- 同一页里，不要连续两行都用"像"
- 写完一个比喻后，接下来至少三句不要用"像"
- 有时直接说一个字：冷。
- 有时用很生活化的说法：泥是真臭。
- 不要每段都给一个精巧比喻

### Rule 19：允许先猜错（新）

AI 的信息组织太工整：
发现异常 → 分析原因 → 引用设定 → 推导 → 结论 → 别人质疑 → 再次验证 → 证实。

真人很多时候：
先猜错 → 被推翻 → 骂一句 → 又试一次 → 又错了 → 再试 → 终于碰对一点。

不要让人物一次就推理正确。
允许他理解错。
允许他判断错。
允许他怀疑错。
允许他跑题。

### Rule 20：伏笔不要太近

AI 伏笔往往是：第一章提 → 第三章兑现。
真人伏笔：第一章提 → 二十章以后才兑现。

不要让同一个场景里的伏笔在同一个场景里就回收。

## Rewrite Workflow

第一遍：删除 AI 连接词。
第二遍：每个场景后加入 20~30% 无效内容（发呆/停顿/闲聊/犯蠢）。
第三遍：对白里至少 1/5 是无关的。
第四遍：不同人物换不同口气说同一个意思。
第五遍：人物加入固定小动作和作者口癖。
第六遍：检查"像"比喻密度，连续两行有"像"就删掉或改。
第七遍：减少解释，允许先猜错。
第八遍：检查每个段落——有没有每一句都在推进剧情？如果有，注入空白。
第九遍：检查节奏——有没有每几百字就一个悬念？如果有，拆掉一个。

## 禁止事项

- 禁止仅替换同义词。
- 禁止故意加入错别字。
- 禁止故意降低文笔。
- 禁止加入病句。
- 禁止改变剧情。
- 禁止改变人物设定。
- 禁止改变世界观。
- 禁止删除伏笔。
- 禁止删减信息。
- 禁止每段都推进剧情。
- 禁止每个场景都有高潮。
- 禁止所有人物用同一个语言水平说话。
- 禁止连续两行都用"像……"比喻。
- 禁止每 300 字就抛一个悬念。
