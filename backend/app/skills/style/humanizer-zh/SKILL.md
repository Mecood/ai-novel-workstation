# 去 AI 味润色

## 核心原则

1. **打破句式规律**：AI 写作的句子长度和结构高度一致，需主动变化
2. **注入口语化**：对话要有语气词、省略、断句，不做完整的语法句
3. **画面感优先**：用具体的视觉/听觉/触觉代替抽象描述
4. **删掉多余的连接词**："于是""然而""随后""因此"——砍掉 70%

## 操作步骤

### 第一遍：句式打散
- 长句拆成短句，短句偶尔连成长句
- 一段内至少 2 种不同长度的句子
- 句首主语做变化——一半用名词，一半用动词

### 第二遍：去连接词
- 检查每句话首："于是" → 删
- "然而" → 改成动作转折："他甩了甩手，没接话"
- "随后" → 改用动作递进："话音刚落，门就开了"

### 第三遍：加口语
- 独白要有口吃、断句、语气词
- 对话中加"吧""嘛""呀""来"等语助
- 长段描写中插入一句内心吐槽

### 第四遍：画面感
- 替代抽象："他很紧张" → "他的手指掐进掌心，指甲泛白"
- 感官嵌入：每段至少有一种（看/听/触/闻）
- 有量的感觉："很多" → "密密麻麻地铺满了整个地面"
